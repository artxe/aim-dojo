# Codex Instructions

`CLAUDE.md` files are the authoritative project instructions.

Read the repository-root `CLAUDE.md` before any work. Once the target files are known, also read every `CLAUDE.md` from the root down to each target file's directory, and load newly applicable ones if the scope changes.

Instructions closer to a target file override broader ones on conflict.

Multi-file procedures (adding a sens game, adding a training mode) live in `.claude/skills/<name>/SKILL.md`; read the matching one before starting such a change.
